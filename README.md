# 🏦 Python Banking System

A simple command-line banking system built with Python.

This project simulates basic banking operations such as creating
accounts, logging in, checking balances, depositing money,
withdrawing money, transferring money, and viewing transaction history.

## 🚀 Features

- Create a bank account
- Account number generation
- PIN-based login
- Check account balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Change PIN
- Admin features
- Store account data locally
- JSON-based data storage

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Object-Oriented Programming
- Command Line Interface (CLI)
